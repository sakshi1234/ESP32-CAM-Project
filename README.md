# ESP32-CAM Web Server

This project uses ESP32-CAM to capture images and stream them over WiFi.

## Features
- Live camera streaming
- WiFi connectivity
- Optimized to fix FB-OVF error

## Hardware
- ESP32-CAM (AI Thinker)
- FTDI Programmer

## How to Use
1. Upload code using Arduino IDE
2. Connect to WiFi
3. Open Serial Monitor
4. Copy IP address and open in browser
